# 3.4 修复记录

3.4 是 v4 前的最后一个准备版本，集中处理 2026-09-16 至 2026-09-18 收到的玩家反馈。发行身份继续使用 `com.frog.offline`、原签名、固定 WebView 地址 `http://127.0.0.1:18763/index.html` 和存档键 `frog.offline.save`；版本为 `3.4 / versionCode 8`，可从同路线旧版覆盖安装。

## 已完成的修复

### 旅行、照片与相册

- 修复普通旅行照片在返程和登录时没有推送到收信流程的问题；旧存档中已生成但未通知的照片会补发。
- 同一明信片模板允许再次寄回，每张使用独立编号；博物馆照片不会因模板已收藏而阻断普通照片收取。
- 放弃保存的普通照片和来访照片进入回收站；相册已满时无法保存的照片同样保留，可恢复且不会重复入站。
- 修复小组件“抓拍”在非全屏模式下因舞台尺寸为 0 而隐藏、取景框越界的问题；补齐局部取景、快门裁切与回忆解锁回归。

### 邻居、友情绘本与庭院

- 困困、胖胖、跳跳在喂食后继续停留到原定离开时间；过期和陈旧请求不会让当前邻居突然消失。
- 喂食后的回礼改为离开时寄入邮箱，按喜爱程度发放三叶草或四叶草，领取邮件后才入账，且不会重复发奖。
- 给喜欢的特产后，邻居离开时留下本人邀约的概率调整为 75%；取消无关的定时随机邀约。
- 修复庭院实体信箱在窄屏默认镜头中被活动按钮遮挡的问题，并覆盖空、已读、未读、邀请引导、进屋返回、拍照及昼夜天气场景。
- 修复庭院昼夜和天气变化不刷新、雨雪效果污染静态季节表、收花后镜头跳回门口的问题。
- 帽子仅在青蛙离家或照镜子时隐藏；蜡烛在青蛙在家且清醒时点亮。

### 嘟嘟商店、购买页与家具

- 单件商品售罄后保留商品行并显示“卖完啦”；全部售罄后仍保留列表，嘟嘟按原定停留时间离开。
- “购买三叶草”改用六档紧凑滚动列表，修复固定列表溢出窗口、商品与按钮错位的问题。
- 新档、旧档和导入存档默认补齐全部 27 件“素风格”家具，同时保留其他已解锁家具和当前摆放。
- 工作台放入或取出材料后立即推送库存；切换其他格子时列表不再显示已耗尽材料，无需关闭工作台即可连续放料。

### 堆肥箱

- 修复第一格空白却始终显示发酵、放入特产后不启动的问题。
- 从有特产的格子中随机选择一格发酵，发酵中锁定该格；完成后消耗 1 份特产、土地肥力 +1，并自动开始下一格。
- 当前周期为 5 分钟，支持重启和离线连续结算；旧的三小时任务保留已过时间并迁移到新周期。
- 隐藏“土地肥力”和“剩余时间”小字，保留原有肥力图标；肥力对作物生长速度暂未增加自定效果。

### 手工品与工作台制作

- 完成通知携带完整物品、图片图层、印章和日期字段，修复桌面成品及详情页空白。
- 只有持有手工品制作工具时才会真正开工；没有工具时可以播放动作，但不会扣料、推进或产生成品，小仓库也不显示“手工品”入口。
- 每件祈愿物或印章开工消耗 1 个手工品材料；三拼护符的每块木片消耗 1 个朽木，材料只扣一次。
- 青蛙回家后收起桌面上已完成的手工品，收藏记录保留；重启或再次出门不会重复摆出旧成品。

### 其他状态修复

- 修复玩家选择的称号不持久化、获得新称号后覆盖当前选择的问题。
- 保留 3.3 已完成的动态照片、广告声音、安卓存档桥和制作人员入口修复。
