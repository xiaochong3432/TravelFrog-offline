# 设计取舍与自定数值

原则：**能用客户端数据/代码证明的一律不自造**。下面全部是本项目自行设定的部分，
逐条列出以便复核与调整；引擎中对应位置都有注释标注。

## 一、为可玩性而设的数值

| 项 | 值 | 理由 |
|---|---|---|
| 起始三叶草 | 9999 | 原版靠长期在线积累，离线版需要一次性给足，避免开局卡在种子/食物价格上 |
| 改名费用 | 首次免费，之后 50 三叶草 | 原版收费口径无法从客户端确认，取一个不影响体验的数值 |
| 旅行节奏 | 出门 12–40 分钟、在家 2–6 分钟 | 原版按小时级节奏设计（`Define.TRAVEL_TIME_MIN = 60`），离线版缩短以便一次游玩完整体验；需要原版节奏时可用环境变量 `FROG_FAITHFUL=1` 切回 |
| 访客回礼后停留 | 20 秒 | 客户端在该动作之后会查询一次邻居，停留过短会触发错误 |
| 手工拼装每阶段 | 90 秒 | 原版由服务端计时，取一个可感知但不必久等的值 |
| 木片掉落 | 12% | 客户端没有任何表给出该掉落，为让三拼玩法可用而设定 |
| 嘟嘟家具商店 | 有货时营业，售罄离开；可重复商品次日按 `shop_limit`（缺省 1）补货，永久限购不重置 | 原版服务端作息表未取得，使用本地自然日提供可持续补货 |
| 基础肥料箱 | 开局摆放木头堆堆（21000），旧档缺失时补齐 | 客户端有完整箱体和六格存取界面，旧引擎没有发放途径导致入口不可见 |
| 出行准备 | 背包或桌子上必须有便当，回家自动解锁行李 | 按试玩反馈调整；无食物不再触发新放浪旅行，旧旅行存档仍可结算 |
| 三个节日活动 | 常开 | 同上；原版按真实日期开关 |
| 广告 / 分享 / 充值 | 直接发奖 / 直接发奖 / 免费发放 | 离线版不含广告与支付，界面中已明确说明 |
| 界面元素 | 「重载界面」按钮、提示文案、悬浮球的颜色与位置 | 属于本项目新增的辅助界面 |

## 二、目的地系统的换算口径

数据本身是原版的，但下列"单位换算"由本项目确定：

| 项 | 口径 |
|---|---|
| 走行预算 | `Define.TRAVEL_TIME_MIN × 3`（边耗时单位是分钟，跨一个区域约需 150–300 分钟；取 1 倍时一趟只走两步，整张边表失去意义） |
| 食物 `HP/H_MAXTIME`、`H_UP` | 按百分比加到旅行时长（原版 `BASE_HP = 100` 作为锚点） |
| `WAY_SPEED` | 该族路段耗时按百分比下降 |
| `WAY_STEP` | 视为"额外步数" |
| `COST_STEP` / `AREA_STEP` | 按百分比增减步数上限 |
| `ITEM_PERCENT`（`I_CLOVER`/`I_CLOVER_RND`/`I_TICKET`） | 视为"多一件的概率"；抽奖券基础概率沿用离线版原有的 45%，每种效果再加 10 点 |
| `ITEM_PERCENT`（`I_UP`） | 每 50 点折算一次额外特产 |
| 步数上限 / 终点判定 | 14 步；走过 3 步之后经过终点才算"抵达"（部分区域的终点紧邻入口，否则一趟只有一步） |
| 门票 `AREA_DECIDE = -2` | 无法作为权重解释，取"该票把行程钉死在这座博物馆"；门票行程可免费通过特殊路段 |
| 门票来源 | 许愿池（每座博物馆 3 张）。原版由"博物馆冒险"发放，而该玩法默认关闭 |
| 彩叶幸运草补缺图 | 携带时本趟第一张照片用于补齐已有画片组中缺失的一张，优先补本趟路过的组 |

## 三、功能性开关

| 项 | 状态 |
|---|---|
| 博物馆"大冒险" | 默认关闭，改为开局解锁全部博物馆图鉴（引擎内常量可改回开启） |
| 探秘东山岛 | 未并入 |
| 1.0.21 增量 | 按需合并（新明信片、家具套、更新后的表），未整体并入 |
| 排行榜 | 客户端自身隐藏入口，未改动 |
| 相册「地图」 | 原版为运营方托管网页，已随服务下线；改为自制的省区足迹页（不绘制行政区划界线，原因见使用限制文档） |

## 四、明确未做的部分

| 项 | 原因 |
|---|---|
| 服务端掉落表相关（`GET_REWARD / DROP_ID`、节点 `drop`） | 该表不在客户端的 60 张表中，也未在 CDN 归档中出现 |
| 堆肥"肥力 → 生长速度" | `compostData` 只有 5 档外观，没有任何速率字段，需要完全自造数值 |
| 旅行中的伙伴遭遇表现（`FRIENDSHIP` / `TRAVELER_STEP`） | 归访客与任务系统；地图节点的"遭遇伙伴 + 概率"字段已解出但未接入玩法 |
| 明信片"中间横带"官方摆位 | 规律无法从数据推出，保持数据表自身坐标 |
| 手绘中国地图 | 公开发布的地图需使用标准地图并标注审图号 |

## 五、可调整的入口

多数数值可通过环境变量覆盖，便于按需回调原版节奏或调整难度：

| 变量 | 作用 |
|---|---|
| `FROG_FAITHFUL=1` | 使用原版调参表中的原始节奏 |
| `FROG_TRAVEL_MIN` / `FROG_TRAVEL_MAX` | 出门时长范围（秒） |
| `FROG_TRAVEL_STEPS` / `FROG_TRAVEL_GOAL_STEPS` | 步数上限 / 终点判定步数 |
| `FROG_TRAVEL_MINUTES` | 走行预算倍数 |
| `FROG_GUEST_ROLL` / `FROG_GUEST_CHANCE` | 邻居串门节奏 |
| `FROG_VISITOR_ROLL` / `FROG_VISITOR_CHANCE` / `FROG_VISITOR_STAY` / `FROG_VISITOR_COOL` | 访客节奏 |
| `FROG_LOTTERY_ROLL` / `FROG_LOTTERY_CHANCE` | 抽奖节奏 |
| `FROG_DRAWING_TRIP` 等 | 绘制/绘本节奏 |
