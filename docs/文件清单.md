# 文件清单

仓库内每个目录的用途，以及哪些是**生成物**（可重建，改动前先看生成器）。

## 顶层

| 路径 | 说明 |
|---|---|
| `README.md` | 项目说明与快速开始 |
| `NOTICE.txt` | 权利归属与告知声明（与游戏内启动页同一份文本） |
| `docs/` | 开发者文档（本目录） |
| `work/` | 全部工程内容 |
| `dist/` | 发行说明、启动器、签名证书（APK 与压缩包不入库） |

## `work/run/` —— 运行主体

| 路径 | 说明 | 生成物 |
|---|---|---|
| `engine/index.js` | 游戏服务端全部逻辑（约 8100 行）：协议分发、存档、旅行与目的地、相册、商店、抽奖、家具与庭院、访客、邮件、任务、图鉴与百科、日历、料理、故事、手工品、活动 | — |
| `engine/protocol.js` | 244 条协议：线名 ↔ 下划线名映射、参数规格 | — |
| `engine/data/gamedata.json` | 60 张客户端表 | ✅ `tools/extract_gamedata.py` |
| `engine/data/define.json` | 原版调参表 | ✅ `tools/build_define_json.py` |
| `engine/data/picture-layers.json` | 明信片合成图层 | ✅ `tools/build_picture_layers.py` |
| `engine/data/travel.json` | 目的地地图（区域/节点/邻接/边/终点/掉落 + 物品效果） | ✅ `tools/build_travel_data.py` |
| `engine/data/tables/*.json` | 逐表导出（60 个） | ✅ 同上 |
| `server/main.js` `server/ws.js` | 路线 A：本地 WebSocket 服务端（调试用） | — |
| `web/index.html` `web/launcher.js` `web/manifest.json` `web/version.json` | 页面外壳 | — |
| `web/js/main.min.js` | 客户端游戏代码（**已应用离线补丁**） | ✅ `tools/patch_game.py` |
| `web/js/main.min.js.clean` | 原版客户端代码（补丁的输入） | ✅ `tools/extract_game.py` |
| `web/js/main.min.js.orig` | 更早一次的客户端快照（diff 用） | — |
| `web/__probe.js` | 路线 B 的接缝：接管 `core.SocketManage`、横幅、存档面板 | — |
| `web/__offline-engine.js` | 内联引擎（引擎 + 协议 + 4 张数据表） | ✅ `tools/bundle_engine.py` |
| `web/map.html` `web/map_data.json` | 相册「地图」省区足迹页 | ✅ `tools/build_map_data.py` |
| `web/resource/` | 客户端原始美术/音频/视频/EAB（约 260 MB，默认不入库） | ✅ `tools/extract_game.py` |
