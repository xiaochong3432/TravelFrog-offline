# 3.1 后续修复

- 屋内默认家具加入动画数据，傍晚和夜间青蛙在家且清醒时显示烛火；睡觉、出门、天亮时及时熄灭并清理光照。
- 屋内订阅青蛙状态更新，读书、打盹、写字、吃饭和睡觉能即时切换。睡觉仅在游戏的夜晚/深夜状态（`hours_type=3/4`）触发，白天、傍晚保持清醒；工作台制作期间显示制作动作。沿用游戏昼夜判断，不另设睡觉时段。
- 花盆每次收获一个对应品种的产物，重复收获同一个空花盆不会再发奖励。收获的鲜花可进入花瓶选择列表，插入时从背包转入花瓶，不复制库存。
- **青蛙在家时仍锁住花瓶**，出门后可换花；换花丢弃原花材，同一枝花重复请求不会消耗。
- 邻里交流的分享额外物品改为先寄邮件、领取后入背包，重复分享不再发奖。旧存档里已提前到账的额外物品不会再发一次，提示明确为“奖励已在背包中”。每日分享奖励仍通过邮件领取；直接到账的商店福利不再误报邮箱。
- 修正邮箱多页加载时被最后一页长度截断的问题。

验证入口：`node work/tools/engine_test.js`；在独立浏览器存档中通过 `work/probe/room_share_regression.js` 检查九种屋内动作、夜间光照、在家锁定/出门插花、单个收获、邮件领取与多页加载。
