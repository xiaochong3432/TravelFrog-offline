## 本仓库的边界

- 仓库中**不包含**客户端的原始美术/音频资源（`work/run/web/resource/`），
  也不包含原始游戏安装包；这两部分请从各自合法持有的副本中提取，
  提取方式见 `docs/数据与逆向说明.md`。
- 仓库中**不包含**任何官方服务端程序；`work/run/engine/` 是依据客户端行为重新实现的本地规则引擎。
- 游戏内启动页会显示与 `NOTICE.txt` 相同的声明，玩家每次启动可见。

## 对使用者的要求

1. 仅用于个人学习、研究与作品保存，不得用于任何商业用途；
2. 不得将本仓库或其产物用于出售、出租、接受捐赠、附带广告或任何变相收费；
3. 再次分发时请保留本文件与 `NOTICE.txt`，并保留游戏内启动页的声明；
4. 若权利人提出异议，应立即停止使用并下架相关内容。

## 关于地图

本项目**不绘制中国行政区划界线**。公开发布的地图须使用标准地图并标注审图号，
自行绘制既不准确也不合规，因此相册中的「地图」以省区名称卡片式的足迹页呈现，
页内也写明了这一点。
