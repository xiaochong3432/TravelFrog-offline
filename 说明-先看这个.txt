怎么玩（三条路，任选一条）
--------------------------------------------------------------------------------

PC 上玩（这个包）：
   1. **双击「旅行青蛙.exe」** ← 推荐，**不需要装 Python，也不需要改系统设置**
      （它是用 Windows 自带的 .NET 编译的，双击就开浏览器进游戏）
   2. 双击 play_frog.bat 也行（它会优先调用上面那个 exe，没有才退回下面两条路）
   3. 装了 Python 的机器可以双击 play_frog.py
   4. 都没有就用 Windows 自带的 PowerShell 版：右键 play-pc.ps1「使用 PowerShell 运行」
   · 一定要"整个文件夹解压"，不要把 exe/脚本单独拿出去 —— 游戏文件在 web 子目录里
   · 关掉那个窗口就是退出游戏服务
   · 四个启动器用的是**同一套端口策略**（见下面第二节），随便用哪个都不会换存档位置

为什么 PC 版必须用启动器而不能直接双击 index.html：
浏览器不允许 file:// 的网页读取本地资源文件，直接双击打不开。启动器只在
127.0.0.1 上开一个**只读**的小服务，把游戏目录发给浏览器，别的什么都不做，
不联网、不上传任何东西。
