# V4.0 更新说明（相对 main 的 V3.6）

> 这份是**给接手开发者的最低限度说明**：本次带上来什么、怎么构建、怎么测、存档兼容性如何。

## 一句话

V4.0 = **main（V3.6）的全部内容** + 并入社区版（"他"的 3.3）剩余机制 + 客户端 21 处改动 + 数据表补齐；
存档版本从 1 升到 **2**，与 V3.7 / V3.3B 可**互相覆盖安装**并共用同一份存档。

## 存档兼容

- `SAVE_VERSION = 2`；老档（v1）自动迁移，未知字段忽略、V4.0 独有字段在他版引擎里也能原样保留。
- 包名统一 `com.frog.offline`，V3.7 / V3.3B / V4.0 共用同一把签名钥 → 可互相覆盖安装；**V3.3/V3.5/V3.6（SAVE_VERSION=1）读到 v2 存档会拒绝覆盖保存**，故未纳入这一组。

## 三方对比结论（V4.0 定稿时实测）

- **V4.0 ⊇ main(V3.6)**：函数 / 常量 / 协议 / 存档字段 **0 丢失**（函数 +88、常量 +77）
- **V4.0 ⊇ 社区版 3.3**：真缺 **0**（剩余差异仅为改名等价、对方函数内部局部闭包、以及"当天随机货架"这类运行时数据）
- 同档 A/B（同一存档喂两边引擎、20 个只读协议逐字段比对）：**16/20 逐字节一致**，其余为有意保留或运行时差异
