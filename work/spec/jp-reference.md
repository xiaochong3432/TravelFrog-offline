### 1.2 ✅ 已解决（第二轮反编译取得确切值）

> 本节原先全部标 🔴，现已由 `work/jp_apk/decomp/Assembly-CSharp.decompiled.cs` 反编译解决。
> **`CloverFarm` 类（行 3609 起）的公开字段就是序列化在场景里的真值。**

| 问题 | **确切答案** | 行号 |
|---|---|---|
| 生长/再生时间 | 每株独立计时：`delay = clamp(rand_normal(μ=7200 s, σ=1800 s), 300 s, 14400 s)`<br>即 **均值 2 小时、标准差 30 分、最短 5 分、最长 4 小时** | 3633–3639（字段）、3831–3832（公式） |
| 庭院生长位数量 | **20 个**（`public int cloverMax = 20;`） | 3631 |
| 四叶草出现概率 | **每株再生时 1 %**（`public float fourLeaf_percent = 1f;`） | 3625 |
| 单株三叶草价值 | **1 点**（`Clover.point = 1`），收割后可持有上限 `CloverMax = 999999` | 3503、11679 |
| 收割方式 | **划动（flick）收割**：`S_FlickChecker`、`hitFlickClover`、`CheckHitClover`、`ScrollAndCloverCheck`；教程 `スライド操作でみつ葉のクローバーを収穫しましょう` | 🟢 |
| 收割动画耗时 | `CloverGetTime = 0.4 s`（收割），`CloverDestroyTime = 0.6 s`（消失动画） | 11675、11677 |

| 四叶草是否占生长位 | 🟡 四叶草是**同一批生长位**中的一株（`NewCloverObject(..., fourLeafFlag: true)` 替换普通株），不额外占位 | 3712 |

> **给引擎的建议**：这 4 个数现在可以直接定死，无需再做成待定参数。

## 14.4 访客（お客さん）完整规则（🟢 反编译实测，行 3257–3360）

**投喂满意度判定**（行 3262–3278）：
```
score = 100 + characterDataFormat.taste[被喂道具的索引]
score >= 180 → 「は 喜んでいます」      (非常高兴)
score >= 160 → 「は 嬉しそうです」      (看起来开心)
score >= 120 → 「は お腹がいっぱいです」  (吃饱了)
否则          → 「は もう食べられません」 (吃不下了)
```

**三叶草回报公式**（行 3338–3350，🟢 原文）：
```
tasteMul  = (100 + taste[itemIndex]) / 100
timeMul   = activeTime / 1800
debuff    = FRIEND_ITEM_DEBUFF[该道具在最近 3 次投喂中的位次]   // 0.6 / 0.75 / 0.9，不在列表则 1.0
cloverGain += (int)( cloverPow * tasteMul * timeMul * debuff / 15 )
```
- `cloverPow` 与 `taste[]` 是 **`CharacterDataFormat` 的字段**（见 §6.1 字段名列表），每个访客一套。
- `activeTime` = 该访客事件的持续秒数（**停留越久给得越多**）。
- **重复投喂同一种道具会被衰减**（0.6/0.75/0.9），这是 `FRIEND_ITEM_DEBUFF` 的作用。🟢
- 赠品种类由 `FRIEND_GIFTPER_NORMAL` / `_RARE` 加权抽取：普通 = 三叶草 80 / 四叶 18 / 券 2；
  稀有 = 三叶草 20 / 四叶 50 / 券 30。🟢
  → **四叶草确实可以从访客处获得**（此前 §6.3 标 🔴，现已确认）。🟢
